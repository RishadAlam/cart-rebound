Cart Rebound listing asset credits
==================================

These are listing images for the wordpress.org directory page only. They are
not part of the shipped plugin code, and .gitattributes keeps the whole
.wordpress-org directory out of release archives.

Regenerate everything with: scripts/build-wporg-assets.sh


Artwork
-------

All artwork is original to this project and fully vector. The mark, layout,
wordmark, palette and icon animation are generated from scripts/brand/brand.mjs;
see docs/BRAND.md for the design rationale.

No third-party, stock or generated imagery is used.


Masters (src/)
--------------

banner-master.svg
icon-master.svg
icon-master-square.svg
	Generated by scripts/brand/build-brand.mjs. Do not hand-edit — they are
	overwritten on the next build.

	The previous listing used raster masters: 3D commerce artwork made with
	OpenAI's built-in image-generation tool, and a wordmark rasterised from an
	Avenir Next-class face that is not redistributable. Needing to ship pixels
	because the type could not be re-set is part of why the pipeline moved to
	vector. Those files are recoverable from git history if ever needed.

Fonts (src/fonts/)
------------------

Archivo-VF.ttf
	Archivo, by Omnibus-Type. SIL Open Font License 1.1 — the full licence is
	in Archivo-OFL.txt in the same directory.

	Build-time only. Every wordmark is outlined to path data before it reaches
	an SVG, so no font file is embedded in, shipped with, or redistributed by
	any asset.


Animation
---------

The icon GIFs are rendered frame by frame from the same geometry as the static
icon (scripts/brand/build-icon-frames.mjs), so the animation cannot drift away
from the mark. Nothing is hand-drawn and no keyframe artwork is involved.
